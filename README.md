# Make Sense of Data with analysis and AI - Andria Arisal

Studi Kasus: Memprediksi Late Payment Invoice (PT Maju Bersama)
Sesuai demonstrasi pemateri, manajer mendapati piutang perusahaan membengkak. Kita akan membuat model Machine Learning menggunakan Python (sebagai representasi algoritma Random Forest dari mesin KNIME yang didemonstrasikan) untuk memprediksi pelanggan mana yang berpotensi telat bayar tagihannya (Late = 1, Not Late = 0).
